# <p align="center"><img src="app/src/main/res/drawable-xhdpi/ic_launcher.png" /><br />fCam - Android4 CCTV</p>

Android-приложение для старых и новых устройств (Android 4.2+): делает серию фото по обнаружению движения
и по HTTP-команде из локальной сети. Без root, без внешних библиотек, маленький APK.

## Как работает

- Сервис работает в фоне (foreground-сервис с иконкой в строке состояния). Для камеры используется
  `android.hardware.Camera`, поэтому приложение совместимо со всеми версиями Android.
- **Движение:** превью камеры уменьшается и сравнивается с предыдущим кадром (примерно 5 раз в секунду).
  Если доля изменившихся точек не меньше порога, делается серия кадров.
- **Серия:** заданное число кадров с заданным интервалом, разрешение всегда максимальное для выбранной камеры.
  На каждый кадр показывается уведомление. Во время серии движение не анализируется.
  Ориентация снимка определяется по датчику положения устройства (при его отсутствии — по повороту экрана)
  и задаётся камере перед серией: фото записываются сразу с правильным поворотом (тег EXIF), без перекодирования.
- **Фото** сохраняются в `DCIM/fCam/`, имена вида `20261012_101500_m1.jpg`
  (`m` — по движению, `e` — по команде, число — номер кадра в серии). Если записать файл не удалось
  (например, нет разрешения), показывается уведомление «снимок не сохранён». Если задан срок хранения («Хранить фото, дней»), после каждой серии удаляются снимки старше этого числа суток
  (по времени изменения файла); при значении 0 снимки не удаляются.
- Устройство предполагается постоянно включённым в зарядку: сервис держит CPU и Wi-Fi.

## Настройки

| Параметр | По умолчанию |
|---|---|
| Автозапуск при загрузке системы | выключен |
| Камера | 0 |
| Порог срабатывания, % изменившихся точек | 2 |
| Минимальное время между сериями, сек (от начала предыдущей серии) | 60 |
| Кадров в серии | 3 |
| Интервал между кадрами серии, сек | 1 |
| Хранить фото, дней (0 — не удалять) | 0 |
| Порт управления (1024–65535, меньшие порты без root недоступны) | 8081 |
| Пароль управления (пусто — авторизация не требуется) | пусто |

Кнопка **START SERVICE** сохраняет настройки и запускает сервис, после запуска она превращается в
**STOP SERVICE**. Пока сервис работает, поля настроек недоступны. В строке состояния выводится адрес
`http://IP:порт/api` (список методов API) с реальным IP устройства; при сбое запуска показывается причина («Ошибка: …»).

**Автозапуск:** если галочка стоит, сервис стартует после каждой загрузки системы, независимо от того,
нажимали ли STOP перед этим.

## HTTP API

Все запросы — `GET` (кроме записи настроек: `POST /api/config`). Пароль передаётся параметром `password` (если он задан в настройках).
Адреса вида `http://адрес:порт/...`.

### Сделать серию кадров

    /api/shot?password=пароль

Срабатывает всегда, кроме случая, когда серия уже идёт (параметр «минимальное время между сериями» не действует).
Ответы: `200 OK`, `403` неверный пароль, `409` серия уже идёт, `503` камера недоступна.

### Список фото (JSON)

    /api/list?password=пароль

    {
      "files": [
        {"name": "20261012_101500_m1.jpg", "size": 4182034, "time": "2026-10-12 10:15:01"},
        {"name": "20261012_101500_m2.jpg", "size": 4179911, "time": "2026-10-12 10:15:02"}
      ]
    }

Размеры файлов в байтах. Общий и свободный объём накопителя вынесены в `/api/info`.

### Сведения о системе (JSON)

    /api/info?password=пароль

    {
      "device_name": "Планшет в прихожей",
      "manufacturer": "samsung",
      "model": "SM-T290",
      "android": "11",
      "sdk": 30,
      "app_version": "1.0.9",
      "time": "2026-10-13 10:15:01",
      "timezone": "Europe/Moscow",
      "uptime_sec": 86400,
      "service_uptime_sec": 3600,
      "battery": {"percent": 100, "charging": true, "plugged": "ac", "temperature_c": 28.5},
      "ip": "192.168.1.157",
      "ips": ["192.168.1.157"],
      "storage": {"total_bytes": 31914983424, "free_bytes": 12345678848},
      "ram": {"total_bytes": 2000000000, "free_bytes": 800000000}
    }

- `device_name` — имя, заданное пользователем в системе (на старых Android берётся имя Bluetooth); если его нет — модель.
- `uptime_sec` — время с последней загрузки системы, `service_uptime_sec` — время работы сервиса fCam.
- `battery` — `null`, если данные о батарее недоступны; `plugged`: `ac`, `usb`, `wireless` или `none`.
- `storage` — объём раздела, где лежит `DCIM`.
- Данные, требующие дополнительных разрешений (имя Wi-Fi сети, уровень сигнала, серийный номер), не выводятся.

### Получить фото

    /api/photo?password=пароль&name=20261012_101500_m1.jpg

Параметр `name` обязателен. Ответы: `200` (`image/jpeg`), `403` неверный пароль,
`404` — нет имени, неверное имя или нет файла.

### Удалить фото

    /api/delete?password=пароль&name=20261012_101500_m1.jpg

Удаляет один файл (только `.jpg` из `DCIM/fCam/`). Параметр `name` обязателен. Ответы: `200 OK`, `403` неверный пароль,
`404` — нет имени, неверное имя или нет файла, `500` — файл не удалось удалить.

### Миниатюра фото

    /api/thumb?password=пароль&name=20261012_101500_m1.jpg

Уменьшенная копия (JPEG, до 320 пикселей по большей стороне, с учётом поворота). Создаётся при первом запросе и
кэшируется в папке кэша приложения (во внутреннем хранилище, не в ОЗУ); лишние миниатюры (без фото) удаляются при запуске сервиса
и после каждой серии. Если создать миниатюру не удалось, отдаётся оригинал. Ответы как у `/api/photo`.

### Настройки (JSON)

    GET  /api/config?password=пароль
    POST /api/config?password=пароль      (тело запроса — JSON)

`GET` возвращает все настройки:

    {
      "autostart": false,
      "camera": 0,
      "threshold": 2.0,
      "min_gap": 60,
      "count": 3,
      "interval": 1.0,
      "keep_days": 0,
      "port": 8081,
      "password": "",
      "cameras": ["Камера 0 (задняя)", "Камера 1 (фронтальная)"]
    }

`POST` принимает JSON-словарь: применяются только присутствующие в нём ключи, остальные не меняются. После сохранения
сервис перезапускается (ответ `200` с новыми настройками отправляется до перезапуска). Ключ `cameras` справочный и при записи
игнорируется. `400` — некорректный JSON или недопустимое значение (в теле ответа текст ошибки). Если меняются `port` или
`password`, дальнейшие запросы нужно выполнять уже с новыми значениями.

### Список методов

    /api
    /api/

Возвращает JSON-словарь «метод → краткое описание». Пароль не нужен.

### Главная страница

    /

Отдаёт файл `DCIM/fCam/index.html`, если он есть (иначе `404`). **Пароль для этого пути не нужен**, поэтому
не размещайте в файле ничего секретного. Другие файлы из папки не отдаются, весь CSS и JavaScript должны быть
внутри `index.html`. Страница может сама обращаться к `/api/list` и `/api/photo` с паролем.

Пример такой страницы — [`fCam/index.html`](fCam/index.html): вход по паролю (запоминается в cookie), свободное место и сведения о системе (`/api/info`),
превью фото (`/api/thumb`), просмотр, выбор и удаление, кнопка ручной съёмки (`/api/shot`), окно настроек (`/api/config`). Скопируйте файл в `DCIM/fCam/`
на устройстве. Страница рассчитана на современные браузеры.

Другие пути — `404`, методы кроме `GET` (и `POST` для `/api/config`) — `405`.

## Безопасность

Сервер рассчитан только на домашнюю локальную сеть: HTTP без шифрования, пароль передаётся в адресе.
Не пробрасывайте порт в интернет.

## Ограничения и особенности

- Приложение собрано под `targetSdk 28`: благодаря этому запись в `DCIM/fCam/` работает напрямую на всех версиях.
  При повышении `targetSdk` запись на Android 10–11+ придётся переделать через MediaStore.
- На новых Android (11+) система может запретить запуск камеры из фонового сервиса сразу после загрузки.
  Если автозапуск не снимает, откройте приложение один раз вручную.
- Нужны разрешения на камеру и на запись в память (на Android 6+ запрашиваются при нажатии START SERVICE).

## Сборка

GitHub Actions собирает APK при пуше тега `v*` и прикладывает его к релизу (`fCam-vX.Y.apk`):

    git tag v1.0.1
    git push origin v1.0.1

Версия берётся из тега. Подпись по умолчанию debug-ключом. Для стабильной подписи (обновление поверх
установленной версии) добавьте секреты репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
