
# <p align="center"><img src="app/src/main/res/drawable-xhdpi/ic_launcher.png" /><br />fCam - Android4 CCTV</p>

Android-приложение (4.2+): серия фото по движению и по HTTP-команде. Без root, без зависимостей.

## Внешняя команда

    http://адрес:порт/api/shot?password=пароль

Ответы: `200 OK`, `403` неверный пароль, `409` серия уже идёт, `503` камера недоступна.
Если пароль в настройках пуст, параметр `password` не нужен.

## Список фото

    http://адрес:порт/api/list?password=пароль

Текст: `total_bytes`, `free_bytes`, `files`, далее строки `имя<TAB>размер<TAB>время`.

## Фото

Папка `DCIM/fCam/` (без разрешения на запись показывается уведомление), имена вида `20261011_153022_m1.jpg`
(`m` — по движению, `e` — по команде).

## Сборка

Создайте тег `vX.Y` и отправьте его на GitHub: Action соберёт APK и приложит его к релизу.
Необязательно: секреты `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`
дают стабильную подпись (иначе подпись debug-ключом, и обновление поверх может не встать).
